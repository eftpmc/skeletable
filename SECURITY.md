# Security policy

## Reporting a vulnerability

Please do not open a public issue for a suspected security vulnerability. Once this repository is public, use GitHub's **Security** tab and its **Report a vulnerability** flow to send a private report with a description, reproduction steps, and any relevant impact.

We will acknowledge the report, investigate it, and coordinate a fix before public disclosure. Private vulnerability reporting must be enabled in the repository settings when the repository is made public.

## Supported versions

Security fixes are applied to the latest deployed version of Skeletable.
